# Setar Mentor

یک پلتفرم وب سبک برای آموزش سه‌تار با امکانات زیر:

- مسیر آموزشی مرحله‌ای از مبتدی تا تحلیل اجرا
- پخش صدای مرجع نت برای تمرین گوش و انگشت‌گذاری
- شنود میکروفون و تشخیص فرکانس اجرای نوازنده به‌صورت زنده
- نمایش میزان اختلاف با نت هدف (برحسب سنت) و پیام اصلاحی فوری

## اجرا

```bash
python3 -m http.server 4173
```

سپس آدرس `http://localhost:4173` را باز کنید.
